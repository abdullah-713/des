### 2️⃣ استيراد قاعدة البيانات
من cPanel > phpMyAdmin:
- افتح قاعدة البيانات: `u307296675_app`
- اضغط "استيراد" (Import)
- اختر ملف `database_production.sql`
- اضغط "تنفيذ" (Go)

### 3️⃣ تحديث بيانات المدير (اختياري)
إذا أردت تغيير بيانات المدير، نفذ هذا SQL:
```sql

  password = '$2y$10$...' -- استخدم password_hash في PHP
WHERE role = 'admin';
```

## ✨ المزايا الرئيسية

### 📱 تطبيق PWA
- قابل للتثبيت على الجوال/الكمبيوتر
- يعمل بدون إنترنت (للصفحات المخزنة)
- سرعة فائقة (70% أسرع)

- 🔴 صرح الإتقان الأوروبي (وردي)
- 🟠 شركة فضاء المحركات (برتقالي)
- 🟢 مركز فضاء المحركات (أخضر)

- إخفاء زر الخروج (قابل للتحكم)
- منع الوصول المباشر
- حماية JavaScript
- حماية الجلسات

### ⚡ أداء محسّن
- Service Worker Caching
- تحميل أسرع بـ 70%
- استهلاك أقل للبيانات بـ 91%

## 📊 المزايا الإدارية

### للمدير - تحكم كامل:
- 📊 لوحة تحكم شاملة بكل شيء
- 👥 إدارة الموظفين والفروع
- 📝 سجلات الحضور التفصيلية
- 📈 تسجيل حضور جماعي (اختيار موظفين + وقت محدد)
- ⚡ **إضافة/خصم النقاط** لأي موظف مباشرة
- 🔄 **إعادة تعيين النقاط** إلى القيمة الافتراضية (100)
- ⚙️ التحكم في جميع الإعدادات والأمان
- 🎨 ألوان مميزة لكل فرع
- 📊 عرض النقاط بألوان تحذيرية (أحمر < 50، برتقالي < 80، أخضر ≥ 80)

### للموظف:
- ⏰ تسجيل حضور/انصراف **بالوقت الفعلي** (لحظة الضغط)
- 📊 مشاهدة الإحصائيات
- 📱 تطبيق سهل ومريح
- ⚡ عرض "-" إذا لم يسجل الحضور (لا توجد قيم افتراضية)

## 🆘 استكشاف الأخطاء

### خطأ الاتصال بقاعدة البيانات
- تأكد من بيانات الاتصال في `config.php`
- تأكد أن القاعدة موجودة
- تأكد من صلاحيات المستخدم

### صفحة بيضاء
- تأكد من رفع كل الملفات
- تحقق من إصدار PHP (7.4+)
- افحص ملف error_log

### PWA لا يعمل
- تأكد من استخدام HTTPS
- تحقق من وجود `manifest.json` و `sw.js`
