========================================
   تعليمات التنقل في السيرفر
========================================

أنت الآن متصل بالسيرفر عبر SSH

الأوامر الأساسية:

1. عرض المسار الحالي:
   pwd

2. الانتقال إلى مجلد public_html:
   cd /home/u850419603/domains/sarh.online/public_html

3. عرض محتويات المجلد الحالي:
   ls -la

4. إنشاء مجلد backup (للملفات القديمة):
   mkdir -p backup_$(date +%Y%m%d)

5. نسخ الملفات القديمة إلى backup:
   cp -r * backup_$(date +%Y%m%d)/

6. عرض المساحة المتاحة:
   df -h

7. عرض حجم الملفات:
   du -sh *
